<h2 align="center">Async Weather & News Dashboard</h2>

<h2 align="center">About</h2>

<p>Project that demonstrates your grasp of asynchronous programming and the event loop. This app should fetch weather data and news headlines from public APIs, showcasing different asynchronous styles, namely:
Callbacks, promises, and async/await</p>
